# ✒️ Handwriter Studio v2.0

> Профессиональный локальный веб-генератор рукописных конспектов и лекций на основе тетрадных листов и кастомных шрифтов.

## ✨ Возможности

- 📷 **Загрузка своих фото тетрадей (Drag & Drop)**: Сфотографируйте свою настоящую тетрадь или выберите любое изображение листа — оно мгновенно применится и сохранится на сервере.
- ✍️ **Движок «Живой руки» (Human Realism Engine)**:
  - Вертикальное дрожание строки (*Baseline Jitter*);
  - Микронаклон отдельных букв (*Slant Jitter*);
  - Хаотичный размер символов и разброс нажима пера (*Ink Flow*);
  - Настраиваемая красная строка (абзацный отступ).
- 📖 **Режимы отображения**:
  - **Разворот**: страницы группируются парами со стилизованным тетрадным переплётом;
  - **Лента**: классический вертикальный стек;
  - **Сетка**: компактный каталог миниатюр.
- 🎨 **Палитра архивных чернил**: классическая синяя шариковая ручка, фиолетовая студенческая паста, черная гелевая, графитовый карандаш 2B, бордовая и хвойная пасты + свободный Color Picker.
- 📄 **Экспорт документов**:
  - Экспорт в чистый многостраничный **PDF** в один клик;
  - Скачивание всех страниц архивом **.ZIP**;
  - Быстрое копирование любого листа прямо в буфер обмена (**Ctrl+V** в мессенджеры).
- 💾 **Пресеты и автосохранение**: встроенные стили (*«Классика»*, *«Плотный конспект»*, *«Беглый почерк»*, *«Карандаш»*) + сохранение текста и настроек в браузере (*LocalStorage*).

## 🚀 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/Rsych09/Handwritter.git
cd Handwritter
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Запуск сервера
Вы можете запустить проект несколькими способами:

- **Через консоль**:
  ```bash
  python main.py
  ```
- **Напрямую в Windows**: дважды кликните по `run_server.bat` или `generator.vbs` (фоновый запуск без окна консоли).

Сервер автоматически откроет вкладку в браузере по адресу:
👉 **[http://127.0.0.1:8000](http://127.0.0.1:8000)**

## 📁 Структура проекта

```text
├── assets/            # Шаблоны тетрадных листов (клетка, линейка, чистый лист, пользовательские)
├── fonts/             # Рукописные шрифты (.ttf, .otf)
├── templates/         # Веб-интерфейс Handwriter Studio (Tailwind CSS, jsPDF, JSZip)
├── main.py            # Бэкенд на FastAPI с REST API загрузки фонов и шрифтов
├── requirements.txt   # Зависимости Python
├── run_server.bat     # Скрипт запуска для Windows
└── generator.vbs      # Скрытый запуск без лишних окон
```
